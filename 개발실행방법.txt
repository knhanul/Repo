NUNI Repository - 개발계 실행 방법
=====================================

1. 가상환경 생성 및 활성화
-------------------------------------
python -m venv .venv
.\.venv\Scripts\Activate.ps1

2. 의존성 설치
-------------------------------------
pip install -r requirements.txt

(테스트를 실행하려면)
pip install -r requirements-dev.txt

3. 환경설정 파일 생성
-------------------------------------
copy .env.example .env

.env 파일을 열어 다음 값을 수정:

  APP_SECRET          : 32자 이상의 랜덤 문자열 (예: openssl rand -hex 32 결과)
  ADMIN_PASSWORD      : 초기 관리자 비밀번호
  NAS_WEBDAV_BASE_URL : NAS WebDAV 주소 (http:// 또는 https:// 로 시작)
  NAS_WEBDAV_USERNAME : NAS WebDAV 사용자 ID
  NAS_WEBDAV_PASSWORD : NAS WebDAV 비밀번호

  ※ NAS WebDAV 연결이 없는 개발 환경에서는 .env.example 의 기본값 그대로도 서버는 시작됩니다.
    단, 파일 업로드/다운로드 등 NAS 관련 기능은 동작하지 않습니다.

4. 서버 실행
-------------------------------------
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload

브라우저에서 http://127.0.0.1:8080 접속

5. 테스트 실행
-------------------------------------
pytest -q

6. Docker로 실행 (배포 환경)
-------------------------------------
docker compose up -d --build

컨테이너는 127.0.0.1:8100 포트에서 서비스됩니다.
